## 摘要
基于点云的3D物体检测器的结构性漏洞仍未被充分理解。先前的工作主要研究孤立3D物体模型上的对抗鲁棒性，而最近的LiDAR欺骗攻击针对更丰富和更真实的驾驶场景，但主要关注物理可实现性，而非理解检测器的行为或攻击效率。在这项工作中，我们研究了基于LiDAR的检测器如何在复杂场景中依赖空间证据，以及这些依赖模式是否可以被利用以更有效地引发故障。为此，我们提出了一种可解释性引导的对抗分析框架。我们引入了显著性LiDAR（SALL）方法，该方法在场景之间聚合积分梯度归因，为基于LiDAR的3D物体检测器生成通用显著性图。在这些图的引导下，我们设计了可解释性感知的视锥攻击（EFA），它选择性地仅扰动最具影响力的视锥，而不是均匀地攻击整个物体区域。在KITTI和nuScenes数据集上，针对PointPillars和SECOND等检测器的实验表明，EFA将检测召回率降低了超过15个百分点，而所需的扰动视锥比最先进的非显著性感知基线少25-50%。这些发现揭示了现代3D检测器将判别性证据集中在少数空间区域，从而暴露了当前LiDAR感知系统中的一个结构性鲁棒性漏洞。我们的代码已在https://github.com/SecMindLab/Saliency_LiDAR发布。

## Abstract
The structural vulnerabilities of point cloud-based 3D object detectors remain poorly understood. Prior work has studied adversarial robustness primarily on isolated 3D object models, while recent LiDAR spoofing attacks target richer and more realistic driving scenes but focus mainly on physical realizability rather than understanding detector behavior or attack efficiency. In this work, we investigate how LiDAR-based detectors rely on spatial evidence in complex scenes and whether these reliance patterns can be exploited to induce failures more efficiently. To this end, we propose an explainability-guided adversarial analysis methodology. We introduce the Saliency-LiDAR (SALL) method, which aggregates Integrated Gradient attributions across scenes to produce universal saliency maps for LiDAR-based 3D object detectors. Guided by these maps, we design the Explainability-aware Frustum Attack (EFA), which selectively perturbs only the most influential frustums rather than uniformly attacking entire object regions. Experiments on KITTI and nuScenes, across detectors such as PointPillars and SECOND, show that EFA reduces detection recall by more than 15 percentage points while requiring 25-50% fewer perturbed frustums than the state-of-the-art non-saliency-aware baseline. These findings reveal that modern 3D detectors concentrate discriminative evidence in a small subset of spatial regions, exposing a structural robustness vulnerability in current LiDAR perception systems. Our code is released at https://github.com/SecMindLab/Saliency_LiDAR.

### 2. 论文提出的方法论

- **核心思想**：提出一种可解释性引导的对抗分析框架，通过生成通用的显著性图来定位检测器最依赖的空间区域，并基于此设计选择性的扰动策略，以极小的扰动代价实现高效的物体隐藏攻击。

- **关键技术细节**：
    - **显著性LiDAR（SALL）方法**：
        - **目的**：为LiDAR场景中的特定物体类别（如汽车、行人）生成通用的、稳定的2D显著性图。
        - **流程**：
            1. **预处理**：从原始点云场景中分离出目标物体点云和背景点。
            2. **积分梯度计算**：对目标点云进行多步扰动（沿射线方向缩放），将扰动后的点云与背景合并输入检测器。计算检测器输出相对于输入点云的积分梯度，生成点级贡献图。
            3. **自适应索引与聚合**：将不同尺寸、方向的目标物体的点级显著性图，通过坐标变换和自适应体素化（例如，归一化到64×32的2D矩阵），然后跨场景进行矩阵相加，最终聚合成该类别的通用显著性图。
    - **可解释性感知的视锥攻击（EFA）**：
        - **目的**：基于SALL生成的显著性图，进行高效的选择性攻击。
        - **流程**：
            1. **提取与2D索引**：提取目标物体点云，并将其离散化到二维网格（类似PointPillars的柱状结构）。
            2. **视锥模拟与选择**：将点云按其水平角度离散化为视锥。根据SALL显著性图计算各视锥的关键性得分。
            3. **关键视锥优先扰动**：在给定的扰动预算下，优先选择并扰动最关键（得分最高）的视锥，而非攻击整个物体区域。扰动方式可为移除或沿射线位移。
            4. **合并**：将扰动后的目标点云与原始背景点云合并，生成对抗样本。

### 6. 论文的主要结论与发现

1. **检测器存在结构性漏洞**：现代3D物体检测器将判别性证据高度集中在少数空间区域。这一结构性依赖使其对针对关键区域的稀疏扰动极为脆弱。
2. **显著性图具有通用性和可转移性**：SALL生成的显著性图揭示了稳定且一致的空间归因模式，这些模式可在不同的检测器架构（PointPillars和SECOND）和数据集（KITTI和nuScenes）之间有效转移，并能通过联合训练进一步增强。
3. **EFA攻击高效且强大**：与均匀扰动整个区域的SOTA方法相比，EFA能在减少**25-50%** 扰动视锥的情况下，实现超过**95%** 的目标隐藏率。对大物体性能提升20-30%，对小物体（行人）提升约23%。
4. **攻击策略比扰动方式更重要**：实验发现，一旦确定了关键区域，具体的扰动策略（移除或位移）对攻击结果影响很小，而视锥选择策略是主导因素。
5. **对物理误差具有鲁棒性**：EFA对现实世界中可能存在的LiDAR欺骗误差和速度相关的扰动约束表现出较强的鲁棒性，攻击成功率仅轻微下降，验证了方法的物理世界攻击潜力。

### 8. 不足与局限
