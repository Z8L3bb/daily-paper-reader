## 摘要
单阶段完全稀疏三维目标检测器依赖点云数据来检测自动驾驶场景中的目标。然而，点云的稀疏性和不完整性严重限制了三维目标检测的性能。为了解决这个问题，本文提出了一种专为单阶段完全稀疏检测器设计的点云补全方法。整个基于形状先验的补全过程由两个连续步骤组成。第一步，我们设计了一个新颖的实例选择模块，即使在基线模型不生成提议的情况下，该模块也能识别出与前景目标对应的点云，同时有效地忽略背景区域的点云。第二步，我们引入了一个新颖的基于对齐的点补全模块，该模块在中心和方向上将前景目标的点云与原型对齐。随后，从原型中选择点来填充前景目标的缺失部分。我们在KITTI数据集上使用两个单阶段完全稀疏检测器评估了我们的方法。实验结果表明，所提方法显著提升了检测性能，证实了其有效性和泛化能力。

## Abstract
Single-stage fully sparse 3D object detectors rely on point clouds data to detect objects in autonomous driving scenarios. However, the sparsity and incompleteness of point clouds significantly limit the performance of 3D object detection. To address this issue, this paper proposes a point clouds completion method specifically designed for single-stage fully sparse detectors. The entire shape-prior-based completion process consists of two consecutive steps. In the first step, we design a novel Instance Selection module, which is capable of identifying point clouds corresponding to foreground objects even when the baseline model does not generate proposals, while effectively ignoring the point clouds of background regions. In the second step, we introduce a novel Alignment-Based Point Completion module, which aligns the point clouds of foreground objects with prototypes in terms of both their centers and orientations. Subsequently, points are selected from the prototype to fill in the missing parts of the foreground object. We evaluated our method on two single-stage fully sparse detectors using the KITTI dataset. The experimental results demonstrate that the proposed method significantly improves the detection performance, confirming its effectiveness and generalizability.

### 1. 论文的核心问题与整体含义（研究动机和背景）
- **核心问题**：单阶段完全稀疏的 3D 目标检测器因其从原始点云中直接预测，性能严重受制于点云的**稀疏性和不完整性**，特别是远距离或遮挡物体的点云质量极低，导致检测瓶颈。
- **背景**：现有的点云补全方法几乎都依赖两阶段检测框架（如生成区域提议后再补全），无法直接适用于不产生提议框、追求高效率的单阶段全稀疏检测器。因此，设计一种**无需区域提议、与单阶段全稀疏架构兼容**的点云补全方法是亟待解决的问题。

### 2. 论文提出的方法论
该方法名为 **SPPCC (Shape-Prior-Based Point Cloud Completion)**，整体嵌入全稀疏检测器，由两个顺序模块构成。

- **核心思想**：利用数据集离线生成的类别级完整形状原型，对检测过程中找到的前景实例点云进行对齐和填充，从而弥补缺失信息。

- **关键技术细节**：
  - **实例选择模块**：从全稀疏骨干网络提取的点特征出发，经过一个 MLP 分类器预测每个点的类别分数，过滤背景点，再用 DBSCAN 聚类生成无提议框的前景实例点云（cluster）。
  - **基于对齐的点补全模块**：
    - **对齐**：将每个聚类实例通过中心偏移预测网络（Centroid Offset Network）平移到原点，再通过 2D 占用表提取航向信息，利用角度网络（Angle Net）预测偏航角，使实例与同类别的**形状原型**在中心与方向上对齐。
    - **补全**：将已对齐的实例点云与原型点云分别体素化，对于实例体素中为空而原型体素非空的区域，从原型中选取点添加到实例中。添加的点数由**补全系数 (CC)** 控制：
      \[
      CC = \frac{N_I}{N_p}, \quad \text{添加点数} = N_i \times CC
      \]
      其中 \(N_I\) 为实例点云点数，\(N_p\) 为原型点云点数，\(N_i\) 为该体素中原型的点数。该系数使补全强度与实例点密度正相关。
  - **原型生成**：基于训练集标注，将各类别所有目标点云中心对齐、航向归零后合并，滤除低反射率点，用最远点采样固定点数（车 2048，自行车和人 512）得到最终原型。
  - **损失函数**：总损失 \(L_{total} = L_I + L_C + L_{bs}\)，其中 \(L_I\) 为点分类的 Focal Loss，\(L_C = 0.5\cdot L_{center} + L_{angle}\)，均为 L1 损失。

### 7. 优点
- **无需提议框**，可为任何不产生区域提议的单阶段全稀疏检测器提供补全能力，填补了该方向空白。
- **模块化设计**，实例选择和对齐补全独立于检测头，易于迁移。
- **补全系数动态调整**，使生成点数与实例点数相关，避免了简单对称补全的不合理性。
- 整个方法计算开销可控（单卡 3090 训练 6 小时，推理延迟增加约 52ms），兼顾了效率。
- 实验覆盖多种检测器、多个数据集和消融分析，说服力强。

### 8. 不足与局限
- **原型依赖标注**：形状原型需从数据集中离线构建，在新场景或新类别上需重新生成，缺乏自适应学习能力。
- **推理速度下降**：尽管可接受，但推理时间从 67ms 增加到 119ms，对于要求极低延迟的应用可能有影响。
- **数据集评估有限**：主要实验基于规模较小的 KITTI，虽然在 waymo-tiny 上做了初步测试，但未在完整 Waymo 或 nuScenes 等大型数据集上验证。
- **补全能力受限于原型**：原型仅为类别平均形状，对于罕见形状或极端视角可能不适用，且不能恢复纹理细节（仅填充点坐标）。
- **聚类稳定性**：使用了 DBSCAN，其在密集场景可能出现欠分割/过分割，文中未深入讨论。
