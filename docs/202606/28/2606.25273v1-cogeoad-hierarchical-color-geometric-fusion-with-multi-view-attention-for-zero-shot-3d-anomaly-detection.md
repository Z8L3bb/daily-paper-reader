## 摘要
零样本三维异常检测对于工业质量检测至关重要，而标注异常样本十分稀缺。同时，现有方法缺乏将互补的二维彩色图像与三维几何结构有效融合的机制，限制了其在统一框架中检测表面和结构缺陷的能力。为解决这些问题，我们提出CoGeoAD，一个基于CLIP的统一框架，通过构建像素对齐的成对多视角图像来融合颜色与几何特征。该框架引入数据驱动的多视角注意力（MVA）机制，自适应聚合三维特征，以及多阶段颜色-几何融合（MS-CGF）模块，分层整合来自两种模态的多层次特征。在MVTec3D-AD和Eyecandies基准上的大量实验表明，CoGeoAD达到了最先进的性能，能有效捕捉复杂工业场景中的结构和纹理异常。我们的源代码已开源：https://github.com/kingdomShu/CoGeoAD。

## Abstract
Zero-shot 3D anomaly detection is essential for industrial quality inspection, where labeled anomaly samples are scarce. Meanwhile, existing methods lack an effective mechanism to fuse complementary 2D color images with 3D geometric structures, limiting their ability to detect both surface and structural defects in a unified framework. To address these issues, we propose CoGeoAD, a unified CLIP-based framework that fuses color and geometric features by constructing pixel-aligned paired multi-view images. The framework introduces a Data-Driven Multi-View Attention (MVA) mechanism to adaptively aggregate 3D features and a Multi-Stage Color-Geometric Fusion (MS-CGF) module to hierarchically integrate multi-level features from both modalities. Extensive experiments on the MVTec3D-AD and Eyecandies benchmarks demonstrate that CoGeoAD achieves state-of-the-art performance, effectively capturing both structural and textural anomalies in complex industrial scenarios. our source code is available at https://github.com/kingdomShu/CoGeoAD.

### 2. 论文提出的方法论

CoGeoAD的核心思想是通过构建**像素对齐的成对多视角图像**，将3D数据解耦为颜色和几何两个互补的表示，再利用多阶段分层融合策略，在保留CLIP强大泛化能力的同时，实现双模态信息的深度融合。

*   **核心思想**：双模态渲染解耦与分层融合。
    *   将3D点云从多视角渲染为**成对的“颜色图”和“几何图”**，明确分离纹理与结构信息。
    *   在**冻结的CLIP编码器外部**进行特征融合，避免灾难性遗忘，保持模型的泛化性。
    *   通过**数据驱动的注意力机制**和**多阶段分层融合**，实现鲁棒的特征聚合与互补。

*   **关键技术细节与流程**：
    1.  **颜色-几何多视角点云渲染**：
        *   将输入点云绕其几何中心进行多角度旋转（X轴5个角度，Y轴4个角度，共生成20个候选视图，后续选9个用于训练），以捕捉复杂表面。
        *   **几何图**：使用统一的中性灰色渲染点云，白底背景，**专用于突出结构异常**。
        *   **颜色图**：使用原始RGB信息渲染点云，**专用于捕捉色差、污渍等纹理缺陷**。
        *   通过**点-像素对应关系**，建立2D图像坐标与3D点云的映射，并利用**可见性掩码**处理遮挡问题，确保能将2D异常分数精准反投影到3D物体表面。
    2.  **数据驱动的多视角注意力（MVA）机制**：
        *   目的：自适应地为不同视角的2D图像分配重要性权重，抑制遮挡或噪声视角，聚焦最能体现异常的视角。
        *   实现：使用一个轻量级的、由卷积层和线性层组成的**像素编码器**，直接从多视角图像本身提取特征，计算出每个视角的视觉得分，再通过带温度参数的玻尔兹曼分布转换为归一化的注意力权重α。
        *   正则化：引入**熵正则化项**，防止注意力权重崩溃至单一视角。
    3.  **多阶段颜色-几何融合（MS-CGF）模块**：
        *   **特征深度聚合**：不使用CLIP仅最后一层特征，而是将中间层分组，利用一个**动态层选择器**（MLP）学习组内各层特征的融合权重，以捕获从浅层纹理到深层语义的多层次异常信息。
        *   **语义相似度计算与聚合**：在各组内计算视觉特征与可学习文本提示嵌入的余弦相似度，得到异常图。再通过一个**可学习的加权求和**机制，聚合不同深度的异常图。
        *   **模态融合**：颜色流和几何流得到各自的点云异常分数后，采用**逐元素最大化**策略进行最终融合。这种“逻辑或”操作能让任一模态检测到的显著异常信号直接体现在最终结果中，避免平均化造成的信号稀释。
