## 摘要
现有的物体感知SLAM系统在实时性能、多类别支持以及生成高保真、语义一致的物体模型之间强制进行权衡。为了解决这一权衡问题，我们提出了DSP-SLAM++，它通过引入异步建图流水线以实现实时性能，并为单目鱼眼-激光雷达传感器套件进行了专门的传感器融合适配，从而扩展了DSP-SLAM框架。实验表明，我们的系统能够为多个物体类别生成细粒度、几何完整的形状，同时通过将最大物体处理延迟降低高达70%（相较于最先进的基线方法），消除了严重的建图线程瓶颈，从而在具有挑战性的25 Hz多类别数据集上实现了稳健的实时性能。这项工作通过使高保真、多类别物体SLAM能够在配备常见鱼眼-激光雷达传感器配置的平台上使用，使其更适用于自动驾驶和机器人操作等现实应用。开源代码可在以下地址获取：[github.com/AUBVRL/DSP-SLAMpp]。

## Abstract
Existing object-aware SLAM systems force a trade-off between real-time performance, multi-class support, and the generation of high-fidelity, semantically coherent object models. To address this trade-off, we present DSP-SLAM++, which extends the DSP-SLAM framework with an asynchronous mapping pipeline for real-time performance and dedicated sensor fusion adaptations for a monocular fisheye-LiDAR suite. Experiments demonstrate that our system generates fine-grained, geometrically-complete shapes for multiple object classes while eliminating severe mapping thread bottlenecks by reducing maximum object processing latency by up to 70\% compared to the state-of-the-art baseline, enabling robust, real-time performance on a challenging 25 Hz multi-class datasets. This work makes high-fidelity, multi-class object SLAM more practical for real-world applications like autonomous driving and robotic manipulation by enabling its use on platforms with common fisheye-LiDAR sensor setups. The open-source code is available at: [github.com/AUBVRL/DSP-SLAMpp].

### 2. 论文提出的方法论

核心思想是**解耦计算密集型任务**并**优化传感器数据处理流程**。关键技术细节如下：

*   **异步建图管道**：
    *   **核心问题**：原 DSP-SLAM 在关键帧上同步执行目标检测和形状重建，导致严重的建图线程堵塞。
    *   **解决方案**：引入**异步重建管道**。局部建图线程作为生产者，将重建任务（点云、掩码、姿态）打包放入一个线程安全的任务队列，并立即用一个 3D 包围盒作为临时占位符插入地图，从而不阻塞主线程。
    *   **工作流**：一个包含两个工作线程的线程池作为消费者，从队列中取出任务，执行耗时的 DeepSDF 优化和网格提取，完成后将结果放入结果队列。局部建图线程周期性地从结果队列取出并集成为完整的高保真网格。
    *   **优势**：保证了建图线程永不堵塞，实现了即时的空间感知和稳定的实时性能。

*   **多类别检测与重建**：
    *   **多类别 2D-3D 关联**：为解决多类别场景下的关联歧义，提出了一种基于全局贪心二分图匹配的策略。
        *   **过程**：仅对同类别检测对计算关联分数 \(S_{i, j}\)，该分数为投影的 3D 点落入 2D 掩码的比例。然后，全局贪心地寻找最大分数进行匹配，并确保匹配是严格的一对一映射，避免歧义。
    *   **类别感知的地图关联**：为不同类别的物体定义了不同的关联搜索半径 \(r_c = \sqrt{l_c^2 + w_c^2}\)，该半径基于该类别的平均尺寸。这解决了对所有类别使用统一距离阈值而导致的关联错误。
    *   **模块化多解码器架构**：为每个物体类别维护独立的、预训练的 DeepSDF 解码器 \(G_c\)。运行时，根据物体的语义标签动态选择对应的解码器进行形状和姿态优化，避免了单一解码器跨类别干扰和过拟合的问题，同时使系统易于扩展。

*   **鱼眼-LiDAR 深度融合**：
    *   **核心挑战**：单目 SLAM 的尺度模糊性，以及鱼眼镜头产生的严重图像畸变。
    *   **尺度恢复**：采用轻量级的 RGB-L 方法，利用 LiDAR 点云为单目视觉 SLAM 提供度量尺度。
    *   **特征对齐**：在处理畸变时，选择了一条效率更高的路径。系统不去畸变稠密的 LiDAR 点云，而是利用 ORB-SLAM3 原生支持，将稀疏的 2D 视觉特征点通过 Kannala-Brandt 模型矫正到一个虚拟的针孔空间，再将 LiDAR 点云投影到该虚拟空间中完成深度关联。
    *   **掩码矫正**：为了准确地将 3D 点云与 2D 语义掩码关联，系统只对掩码的轮廓点进行鱼眼畸变矫正，然后重建为无畸变掩码。这种方法在保证精度的同时，计算开销极小。
