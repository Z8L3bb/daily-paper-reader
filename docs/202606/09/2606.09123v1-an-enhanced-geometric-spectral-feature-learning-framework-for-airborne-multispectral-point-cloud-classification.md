## 摘要
多光谱点云（MPC）由三维空间-光谱信息构成，在精确土地覆盖分类方面具有巨大潜力。然而，分类模型的表示能力受限于航空MPC固有的高维异构空间-光谱信息、不平衡的样本分布以及类间光谱相似性。我们构建了两个MPC数据集，并提出了一种基于注意力机制的增强型几何-光谱特征学习框架，用于航空MPC分类。我们模型的一个关键组件是带有注意力机制的双流特征融合方法，它增强了高维异构MPC空间-光谱特征的表示能力。第一个流旨在通过融合自注意力提取位置编码的全局光谱特征，第二个流包含多核点卷积和特征聚合注意力，以提取光谱引导的几何特征。然后，我们开发了一个残差注意力融合模块，以整合来自两个并行流的最具信息量的几何-光谱特征。本工作的另一个重要贡献是一个联合损失函数，以提高对不平衡和类间相似样本的学习能力。在两个航空MPC数据集上的实验结果表明，与最先进的方法相比，所提方法具有有效性。此外，本文使用的代码和数据集将在https://github.com/HITlixian/TGRS_GSFF免费提供。

## Abstract
Multispectral point cloud (MPC) is composed of 3D spatial-spectral information, which holds tremendous potential for accurate land-cover classification. However, the representation power of classification models is limited by inherent high-dimensional and heterogeneous spatial-spectral information, unbalanced sample distribution, and inter-class spectral similarity of airborne MPCs. We build two MPC datasets and propose an enhanced geometric-spectral feature learning framework based on attentions for airborne MPC classification. A key component in our model is a two-stream feature fusion method with attention mechanisms, which enhances the representation capability of spatial-spectral features from high-dimensional heterogeneous MPCs. The first stream aims to extract position-encoded global spectral features with fusion self-attention, and the second stream comprises a multikernel point convolution and feature aggregation attention to extract spectral-guided geometric features. We then develop a residual attention fusion block to integrate the most informative geometric-spectral features from the two parallel streams. Another important contribution of this work is a joint loss function to improve the learning ability on unbalanced and interclass similar samples. Experimental results on two airborne MPC datasets demonstrate the effectiveness of the proposed method compared with the state-of-the-art methods. Furthermore, the codes and datasets used in this paper will be made available freely at https://github.com/HITlixian/TGRS_GSFF.

### 2. 论文提出的方法论

该论文的核心是一个基于**注意力机制的双流几何-光谱特征融合框架**，并辅以**针对性的联合损失函数**。

*   **核心思想**：并行提取位置感知的全局光谱特征与光谱引导的局部几何特征，然后通过注意力机制进行自适应、信息丰富的深度融合。

*   **关键技术细节与流程**：
    *   **网络架构（轻量级编码器-解码器）**：
        *   基于RandLA-Net架构，完全使用点卷积构建，包含四个编码层和四个解码层。
        *   每个编码层都是一个核心的“双流特征融合方法”，包含三个关键组件。
    *   **关键组件一：位置编码的全局光谱特征提取器**
        *   **目标**：提取融合了空间位置信息的全局光谱特征。
        *   **流程**：
            1.  **全局光谱特征提取**：使用**2D点卷积**（而非传统的MLP）对每个点的K近邻域的全波段光谱信息进行卷积，以捕获光谱通道间的全局相关性。
            2.  **局部空间位置编码**：使用另一个**2D点卷积**对中心点与其邻域点的相对坐标差值进行编码，以保持空间几何结构并实现位置感知。
            3.  **光谱-位置融合自注意力**：将位置编码特征与全局光谱特征拼接，通过一个2D点卷积生成注意力图，并用此图对光谱差异特征进行重标定，最终通过最大池化输出位置感知的全局光谱特征。
    *   **关键组件二：光谱引导的几何特征提取器**
        *   **目标**：在全局光谱特征指导下，提取具有判别力的局部几何相关性特征。
        *   **流程**：
            1.  **生成光谱引导张量**：使用1D点卷积从邻域点的光谱特征差异中学习一组权重，生成光谱引导矩阵（引导信号）。
            2.  **测量光谱-几何相关性**：将生成的**三重**光谱引导张量与相对空间位置矩阵进行批次化点积，得到光谱引导下的几何相关性特征。
            3.  **特征聚合注意力**：使用一个点卷积层处理相关性特征并经过Sigmoid激活，生成注意力图，用于增强信息丰富的几何相关性特征并抑制无用特征。
    *   **关键组件三：集成几何-光谱特征学习（残差注意力融合）**
        *   **目标**：自适应地整合来自上述两个并行流的特征。
        *   **流程**：
            1.  **初始融合**：将两个流的输出特征拼接，并用1D点卷积进行初步融合。
            2.  **残差注意力**：对初始融合特征，通过1D点卷积和Sigmoid函数生成一个归一化的重要性权重图。将该权重图乘回初始特征，并与原始输入进行**残差连接**，最终生成更具判别力的集成几何-光谱特征。
    *   **联合损失函数**：
        *   **目标**：解决长尾分布和类内光谱变异性问题，增强类内紧凑性和类间可分性。
        *   **组成**：总损失 = 交叉熵损失 + λ · 联合损失
        *   **联合损失** = log(1 / (长尾中心损失 + 最小间隔损失))
        *   **长尾中心损失**`L_lc`：在传统的中心损失基础上，为每个类别引入一个**调制因子**（与类别样本数量成反比），使样本稀少的类别在损失中占据更大权重，从而强制增强多数类和少数类的类内紧凑性。
        *   **最小间隔损失**`L_mm`：计算所有类别中心之间**最小的**成对距离，并最大化该距离，迫近最相似的两个类别在特征空间中分开，以解决类间相似性。
