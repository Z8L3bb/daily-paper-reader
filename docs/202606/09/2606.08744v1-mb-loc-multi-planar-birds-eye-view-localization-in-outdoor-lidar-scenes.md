## 摘要
全局LiDAR定位是自主导航系统的基础任务。最近的方法通过执行场景坐标回归（SCR）并预测密集的3D世界坐标，相比绝对位姿回归（APR）方案取得了更高的精度。然而，SCR方法引入了两大瓶颈：处理原始3D几何带来的严重计算效率低下，以及在不同传感器视角下性能显著下降。为了解决这些限制，我们提出了MB-Loc，一个轻量级且对视角鲁棒的SCR框架。MB-Loc不依赖复杂的3D卷积，而是将输入的LiDAR扫描投影到2.5D多平面鸟瞰图（BEV）表示中。通过沿Z轴对点云进行切片，并将带符号深度映射到离散的2D平面，MB-Loc保留了必要的3D几何结构，同时利用了标准2D CNN的计算易处理性。为了应对室外LiDAR固有的稀疏性，我们引入了一个KL正则化的潜在瓶颈，该瓶颈显式地建模空间不确定性，而无需注入随机噪声。最后，为了确保旋转鲁棒性，我们在平面投影之前应用3D空间增强，迫使网络隐式地学习视角不变的特征。我们在公开的NCLT数据集上进行了大量实验，证明我们的方法优于当前最先进的技术。MB-Loc以实时推理速度运行，在计算效率上显著优于传统的3D-SCR架构。

## Abstract
Global LiDAR localization is a fundamental task for autonomous navigation systems. Recent methods perform Scene Coordinate Regression (SCR) and achieve superior accuracy over Absolute Pose Regression (APR) solutions by predicting dense 3D world coordinates. However, SCR approaches introduce two major bottlenecks: severe computational inefficiency from processing raw 3D geometries and significant performance degradation under varying sensor viewpoints. To address these limitations, we present MB-Loc, a lightweight and viewpoint-robust SCR framework. Instead of relying on heavy 3D convolutions, we project the input LiDAR scan into a 2.5D Multi-planar Bird's-Eye View (BEV) representation. By slicing the point-cloud along the Z-axis and mapping signed depths into discrete 2D planes, MB-Loc retains essential 3D geometric structures while exploiting the computational tractability of standard 2D CNNs. To handle the inherent sparsity of outdoor LiDAR, we introduce a KL-regularized latent bottleneck that explicitly models spatial uncertainty without injecting stochastic noise. Finally, to ensure rotation robustness, we apply 3D spatial augmentations prior to planar projection, forcing the network to implicitly learn viewpoint-invariant features. We perform extensive experiments on the publicly available NCLT dataset and demonstrate that our proposed method outperforms the current state-of-the-art. Operating at real-time inference speeds, MB-Loc significantly outperforms traditional 3D-SCR architectures in computational efficiency.

  - **计算效率低**：多数 SCR 网络依赖 3D 稀疏卷积或点云网络，推理开销大，难以实时部署。

- **整体含义**：MB-Loc 提出一种轻量、视角鲁棒的 SCR 框架，既保留 3D 几何细节，又利用 2D CNN 高效运算，实现精度与速度的突破。

### 2. 方法论
MB-Loc 的核心思想是**将 3D 点云转化为多平面鸟瞰图（2.5D BEV），用 2D CNN 回归稠密空间偏移，最后通过 RANSAC + SVD 恢复全局位姿**。

#### 2.1 2.5D 多平面 BEV 表示
- 输入点云 P = {pi ∈ R³}，沿 Z 轴均匀划分为 P 个水平切片，厚度 w_z = (z_max − z_min)/P。
- 每个点 pi 被分配到平面 k = clamp(⌊(z_max − z_i)/w_z⌋, 0, P−1)，同时将其 (x,y) 映射到 G×G 的 2D 网格 (u,v)。
- 每平面内定义局部深度参考 z_start^(k)，计算带符号相对深度 δz_i = z_i − z_start^(k) + ε，碰撞时保留最小绝对 δz_i 的点。
- 生成四个张量：投影点张量 V（含深度）、二值掩膜 M、局部坐标张量 C_LiDAR、世界坐标张量 C_world。
- 回归目标是空间偏移 Δ = C_world − C_LiDAR，使网络预测有界的局部偏移而非绝对坐标，缩小解空间。

#### 2.2 网络架构
- **编码器**：全卷积残差网络，配合 CBAM（通道+空间注意力）让网络聚焦于信息量大的平面和结构，忽略空区。编码器将 P×G×G 输入下采样为 512 通道的潜特征图（网格尺寸 G/32）。
- **确定性潜在瓶颈**：为避免过拟合稀疏噪声，用三个并行 1×1 卷积分支预测 μ、σ（经 Softplus 激活）和缩放因子 s（经 ReLU 并截断到 s_max）。最终潜变量 Z = μ + s⊙σ。配合 KL 散度正则化，使 (μ, σ) 接近标准正态分布，平滑特征流形，但不引入随机采样，保证确定性推断。
- **解码器**：通过转置卷积对 Z 上采样回原始分辨率，输出 Δ 估计，尺寸为 3P×G×G。

#### 2.3 训练目标
- 坐标损失：L_coord = 均值绝对误差（L1），仅在掩膜 M 标记的占用格点上计算，避免空区干扰。
- KL 正则化：L_KL = 1/(2CH′W′) Σ (μ²+σ²−1−log(σ²+γ))，防止 σ 坍缩为零、强制潜空间平滑。
- 总损失：L_total = L_coord + λL_KL。

#### 2.4 位姿优化
- 由 M 提取对应点对 (C_LiDAR, C_world_hat)，使用 RANSAC 迭代采样 3 对点，Kabsch 算法求解刚性变换（R,t）。
- 动态估计内点率，提前终止，最后对所有内点进行 SVD 精化。设定置信度 p=0.95，阈值 τ=4.0 m，最大对应数 N_max=2000。

#### 2.5 旋转增强
- 训练前对 80% 的扫描随机旋转 -180°~180°，50% 扫描在 x,y 方向平移 ±2 m，投影前施加，迫使网络学习视角不变特征。
