## 摘要
全局LiDAR定位是自主导航系统的基础任务。近期方法通过场景坐标回归（SCR）预测密集的三维世界坐标，相比绝对位姿回归（APR）方案取得了更高的精度。然而，SCR方法引入了两个主要瓶颈：处理原始三维几何带来的严重计算低效，以及在不同传感器视角下性能的显著下降。针对这些局限，我们提出了MB-Loc，一种轻量且视角鲁棒的SCR框架。MB-Loc摒弃了繁重的三维卷积，将输入的LiDAR扫描投影为一种2.5D的多平面鸟瞰（BEV）表示。通过沿Z轴切分点云，并将有符号深度映射到离散的二维平面，MB-Loc在保留关键三维几何结构的同时，利用了标准二维CNN的计算易处理性。为应对室外LiDAR固有的稀疏性，我们引入一个KL正则化的潜在瓶颈，该瓶颈能够显式地对空间不确定性建模，而无需注入随机噪声。最后，为确保旋转鲁棒性，我们在平面投影之前施加三维空间增强，迫使网络隐式学习视角不变特征。我们在公开的NCLT数据集上进行了大量实验，结果表明我们的方法优于当前最先进的技术。MB-Loc以实时推理速度运行，在计算效率上显著超越传统的3D-SCR架构。

## Abstract
Global LiDAR localization is a fundamental task for autonomous navigation systems. Recent methods perform Scene Coordinate Regression (SCR) and achieve superior accuracy over Absolute Pose Regression (APR) solutions by predicting dense 3D world coordinates. However, SCR approaches introduce two major bottlenecks: severe computational inefficiency from processing raw 3D geometries and significant performance degradation under varying sensor viewpoints. To address these limitations, we present MB-Loc, a lightweight and viewpoint-robust SCR framework. Instead of relying on heavy 3D convolutions, we project the input LiDAR scan into a 2.5D Multi-planar Bird's-Eye View (BEV) representation. By slicing the point-cloud along the Z-axis and mapping signed depths into discrete 2D planes, MB-Loc retains essential 3D geometric structures while exploiting the computational tractability of standard 2D CNNs. To handle the inherent sparsity of outdoor LiDAR, we introduce a KL-regularized latent bottleneck that explicitly models spatial uncertainty without injecting stochastic noise. Finally, to ensure rotation robustness, we apply 3D spatial augmentations prior to planar projection, forcing the network to implicitly learn viewpoint-invariant features. We perform extensive experiments on the publicly available NCLT dataset and demonstrate that our proposed method outperforms the current state-of-the-art. Operating at real-time inference speeds, MB-Loc significantly outperforms traditional 3D-SCR architectures in computational efficiency.

## 2. 方法设计
### 2.1 核心思想
将3D点云投影为 **2.5D 多平面鸟瞰图（Multi-planar BEV）**，利用标准2D CNN高效提取几何特征，并通过确定性潜在瓶颈和空间增强提升鲁棒性。

### 2.2 关键技术
- **Z轴切片投影**：
  - 将点云沿Z轴划分为P个水平平面，每个平面厚度 `wz = (zmax - zmin) / P`。
  - 点云由高到低分配平面索引 `k`，并映射到`G×G`的二维网格`(u,v)`。
  - 在相同网格单元内，保留绝对相对深度`|δz|`最小的点（`δz = zi - z_start`），生成稀疏投影张量，同时构建有效性掩码M、局部坐标`C_LiDAR`和世界坐标`C_world`。
- **网络架构**（ResNet风格编码器-解码器）：
  - **编码器**：残差块下采样32×，集成CBAM注意力机制，自动聚焦信息量最大的Z切片平面。
  - **确定性潜在瓶颈**（创新点）：
    - 三个并行的1×1卷积头分别预测均值`μ`、标准差`σ`（Softplus激活）和尺度因子`s`（ReLU截断）。
    - 生成潜在状态 `Z = μ + (s ⊙ σ)`，不引入随机采样，但通过KL散度惩罚强制`σ`不崩塌，起到特征平滑和不确定性建模作用。
    - KL正则项：`L_KL = 1/(2CH'W') ∑(μ^2 + σ^2 - 1 - log(σ^2+γ))`。
  - **解码器**：转置卷积上采样32×，输出稠密偏移预测`ˆΔ ∈ R^(3P×G×G)`，重塑为`P×3×G×G`。
- **训练损失**：
  - L1回归损失（仅计算有效像素）：`L_coord = 1/|M| ∑ M·‖Δ - ˆΔ‖₁`。
  - 总损失：`L_total = L_coord + λ·L_KL`，λ=1×10⁻⁴。
- **位姿求解**：提取预测的世界坐标`ˆC_world = C_LiDAR + ˆΔ`，用RANSAC（最少3点）结合SVD求解刚性位姿变换，设置距离阈值τ和最大子集数量Nmax。

### 2.3 旋转鲁棒性增强
- 训练时，投影前对输入点云随机进行**Yaw旋转**（80%概率，±180°）和**XY平移**（50%概率，±2m），使网络学习视角不变特征。

## 6. 主要结论与发现
- MB-Loc在NCLT上达到**最优平均精度**（0.91m / 2.30°），且是所有序列中唯一实现亚米级精度的方案。
- **计算效率大幅领先**3D-SCR：较SGLoc加速6.9×，较DiffLoc加速2.6×，参数量仅16万。
- 2.5D投影与确定性KL瓶颈的组合有效抑制了噪声和量化误差，提高了跨季节泛化能力。
- 投影前的空间增强使网络对航向角变化具有强鲁棒性。
- 适度增加Z切片数和网格分辨率可提升精度，但过度增大并不会带来显著增益。

## 7. 优点
- **轻量高效**：首次在SCR框架中实现纯2D CNN处理，打破计算瓶颈，达到实时性能。
- **保留几何结构**：多平面BEV解决了传统单层BEV的垂直遮挡问题，维持了关键三维信息。
- **鲁棒设计**：KL正则化瓶颈作为确定性平滑器而非随机采样器，更适合稠密度量回归；空间增强模块使模型视角不变。
- **全面的实验验证**：不仅对比大量基线，还从消融、重建质量、不确定性分析等多角度论证。
- **代码开源**（承诺公开），有益于复现和社区发展。

## 8. 不足与局限
- **地形假设**：依赖固定Z轴水平切片，在高度曲折或非平坦地形上可能失效。
- **动态环境**：未利用多帧时序信息，对严重遮挡难以处理。
- **极度稀疏场景退变**：在仅4096点的下采样Oxford数据集上，性能下降明显（2.64m/1.70°），虽优于SGLoc/LiSA但不及LightLoc，说明量化碰撞问题在极低密度点云中加剧。
