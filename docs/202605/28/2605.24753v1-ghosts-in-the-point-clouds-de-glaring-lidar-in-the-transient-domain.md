## 摘要
现代激光雷达正迅速从笨重的机械扫描系统转向超紧凑、低成本、固态阵列。这种小型化在带来可扩展性、可负担性和类似相机的数据结构的同时，也引入了一种新的严重故障模式：内部多路径眩光。当来自明亮或逆反射表面的光在激光雷达内部反射和散射时，本应到达单个像素的光会扩散到整个像素阵列。由此产生的伪影创建出虚影物体，遮蔽真实物体，并产生对安全至关重要的“点云中的幽灵”。本文介绍了一种基于物理的传感模型和算法技术来解决这一效应。我们表明，内部眩光可以表示为一个线性、与场景无关的算子 —— 瞬态眩光扩散函数（TGSF）—— 作用于瞬态测量。基于此模型，我们开发了一种无需训练的方法，该方法在点云形成之前对低级激光雷达探测（或回波）进行操作，利用眩光扩散函数的知识推断每个探测源于眩光的可能性。由此产生的方法与现有的激光雷达信号处理管道兼容，并可部署在未改装的商用传感器上。通过使用真实的单光子激光雷达硬件进行实验，我们展示了在保留真实场景结构的同时，对严重眩光伪影的大幅抑制。

## Abstract
Modern LiDARs are rapidly transitioning from bulky, mechanically scanned systems to ultra-compact, low-cost, solid-state arrays. This miniaturization-while enabling scalability, affordability, and camera-like data structures-introduces a new and severe failure mode: internal-multipath glare. When light from a bright or retroreflective surface reflects and scatters within the LiDAR, light that should reach a single pixel spreads across the pixel array. The resulting artifacts create phantom objects, obscure real ones, and produce safety-critical "ghosts in the point clouds." This paper introduces a physically grounded sensing model and algorithmic techniques for addressing this effect. We show that internal glare can be represented as a linear, scene-independent operator-the Transient Glare Spread Function (TGSF)-acting on the transient measurements. Building on this model, we develop a training-free approach that operates on low-level LiDAR detections (or echoes) prior to point-cloud formation, leveraging knowledge of the glare spread function to reason about the likelihood of each detection arising from glare. The resulting approach is compatible with existing LiDAR signal-processing pipelines, and deployable on unmodified commercial sensors. Using experiments with real single-photon LiDAR hardware, we demonstrate substantial suppression of severe glare artifacts while preserving true scene structure.

### 论文核心问题与整体含义（研究动机和背景）

现代激光雷达正从传统的机械扫描结构向超紧凑、低成本的固态阵列（SPAD阵列）快速演进。这种“相机化”趋势虽然大幅提升了可扩展性和分辨率，但也引入了一个致命缺点：**内部多路径眩光**。

- 当激光遇到高反射率物体（如道路反光标志、车牌、施工锥等）时，返回的光线会在传感器镜片和阵列之间发生多次内部反射和散射，本应聚焦于单个像素的光，会扩散到周围一大片像素。
- 这会造成严重伪影：产生虚假的“幽灵”物体（如高速公路上凭空出现的墙壁）、掩盖真实目标（如站在反光标志旁的人可能被完全遮挡）。这些“点云中的幽灵”是自动驾驶等应用中的安全关键故障模式。
- 传统机械式激光雷达通过复杂的光学隔离和分时扫描设计规避了此问题，但也导致了体积、成本和运动伪影等缺陷。新一代固态雷达打破了这种设计约束，使得眩光效应成为普遍且严重的挑战。
- 现有方法多在点云形成后处理（如深度学习分类），但此时伪影已与真实几何结构纠缠不清，难以干净分离。**本文的核心思想在于**：眩光应在信号处理的最早期阶段——即点云形成之前的瞬态域（回波层面）——被识别和抑制。

### 论文提出的方法论

论文的核心是构建一个基于物理的瞬态眩光模型，并设计一套无需训练、直接处理低级检测回波的去眩光算法。

- **1. 瞬态眩光扩散函数（TGSF）模型**
  - 眩光形成被建模为一个线性、与场景无关的过程。定义了一个 **瞬态眩光扩散函数 (TGSF)** ，该函数描述了理想无眩光瞬态测量信号如何通过内部光路重新分布，形成包含眩光的测量数据。
  - 由于传感器内部光路的时延极短，可忽略不计，TGSF可简化为一个时间无关的 **眩光扩散函数 (GSF)** 。这意味着，激光雷达数据立方体中的每一帧时间切片都可以看作一幅受眩光污染的独立图像，其扩散模式一致。

- **2. 回波空间的眩光模型**
  - 激光雷达信号处理管线会将原始直方图转换为若干低级的 **回波 (Echo)** 检测（每像素、每帧提取少量峰值的时间、强度和方差）。
  - 论文将GSF模型从连续瞬态域“冻结”到离散的回波空间。对于任意像素u上检测到的回波k，其预测的眩光强度可以表示为**所有其他像素回波强度 经过GSF加权和时序重叠函数校正后的总和**。这构成了一个线性系统。

- **3. 联合光子堆积校正**
  - 眩光总是与极高强度的回波（来自反光体）同时出现，这会引发严重的 **光子堆积（Pileup）** 非线性失真，导致测得的强度偏低、距离偏近。
  - 论文提出了一种基于矩的方法进行校正：通过构建**堆积前向模型**，预计算不同真实光子强度和噪声水平下的**方差和均值偏移查找表 (LUT)**。在实际测量时，根据测得的回波方差反查出真实强度，再根据真实强度查出均值偏移量并进行修正。

- **4. 基于二项似然的置信度指标与去眩光**
  - 首先使用校正后的回波强度和GSF，通过**反向投影**快速估算每个回波位置的预测眩光强度。
  - 然后引入一个 **二项分布置信度指标**：将检测到的光子计数 `Y` 与仅由预测眩光产生的预期计数 `NPG` 进行比较。如果 `Y` 远大于 `NPG`，则置信度高，该回波更可能来自真实表面；反之则极可能是眩光伪影，置信度为零。
  - 算法工作流程为：原始直方图 -> 回波检测 -> 堆积校正 -> 眩光预测 -> 计算置信度 -> **在每像素的多重回波中选择置信度最高的那个作为最终深度**，从而抑制眩光回波。

### 实验设计

  - 车牌
  - 交通锥

  - 安全关键场景：模拟一个穿高可见度背心的孩子（黑色人体模型）站在标志和交通桶旁边，验证能否在抑制眩光的同时保留对人体模型的检测。

### 论文的主要结论与发现

- **内部多路径眩光是未来固态激光雷达的一个根本性、危险故障模式**，必须在点云生成前的低层信号处理阶段解决。
- **提出的TGSF模型能够物理准确地描述这种效应**，将其转化为一个线性、与场景无关的算子，为算法处理奠定了基础。
- **开发的训练无关、基于置信度的回波筛选方法**，能有效识别并抑制由眩光引起的虚假回波，同时完好保留来自真实物体的回波信号。
- **光子堆积与眩光是共生的高强度信号问题，必须被联合处理**。在回波空间对两者进行校正，是实现鲁棒去眩光的关键。
- 方法能够成功兼容现有LiDAR信号处理管线，并可直接部署于未经改装的商用传感器上，展示了极高的实用价值。

### 优点（方法或实验设计上的亮点）

- **物理直觉清晰，方法论扎实**：将复杂的内部光路散射问题提炼为线性扩散函数，问题建模非常优雅。
- **介入时机精准**：在光子计数和回波层面进行操作，避开了在点云或深度图层面处理所带来的信息损失和几何纠缠问题，这是其核心优势。
- **无需训练，通用性强**：不依赖大规模标注数据，其模型仅取决于传感器自身的GSF特性，理论上可在任意场景中开箱即用，泛化能力远超基于学习的方法。
- **实用且模块化**：算法设计轻量，可直接嵌入标准的信号处理管道，支持回波级的置信度输出，便于下游任务使用。
- **实验对比维度充分**：对比了学习法和传统摄影法，并通过有无堆积校正的实验，深刻揭示了联合处理的必要性，论证非常有说服力。

### 不足与局限

- **实验场景受限**：所有实验均在室内环境下进行，尚未在具有强烈太阳背景光等噪声的户外真实交通场景中测试，方法的鲁棒性有待进一步验证。
- **对校准的依赖**：方法高度依赖事先精确测量的GSF。GSF的有效性可能在真实部署中因灰尘、冷凝水、镜头刮擦等影响而退化，需要研究校准的长期有效性和自适应性。
- **GSF的空间可变性处理**：论文通过测量49个位置的GSF并进行插值来应对空间变化，这种处理方式的精度和鲁棒性，特别是对视野边缘区域，可能有限。
- **背景模型简单**：将环境光建模为均匀的“背景噪声”可能过于简化。在实际场景中，背景光分布可能不均匀，这会影响到堆积模型和二项式似然计算的准确性。
