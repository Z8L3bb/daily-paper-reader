## 摘要
随着森林监测向可扩展、精细的三维量测发展，森林 LiDAR 点云的自动化实例分割日益关键。然而，树木实例的标签稀缺制约了进展；一公顷林地可包含数百万个点和数百个重叠、复杂的树冠，从原始数据开始手工标注既费力又容易出错。标注通常由自动预分割结果修正而来，但因缺乏交互或 AI 辅助精化，成本依然高昂。受基础分割模型可提示范式的启发，我们提出了 SelectAnyTree，这一可提示实例分割模型仅需几次点击即可在三维森林点云中描绘出任意单株树木。它引入了两个关键组件：点击至查询的提示编码器与冠层高度模型（CHM）引导的首次提示。前者将每次点击转换为单一内容查询，编码其三维位置与正/负极性以及池化的局部骨干特征；后者则无需任何用户输入，提供几何与生态引导的树梢作为首次提示。生成的提示查询随后由状态空间查询解码器解码为单个树木掩膜，以线性时间复杂度高效捕获大规模森林场景中的长距离上下文。我们在七个不同的森林区域和一个独立的保留测试数据集上评估了 SelectAnyTree 的交互与实例水平性能，展示了超出训练域的强大泛化能力。从单次点击开始，该模型对目标树木的分割达到 78.2 的交并比（IoU），比最强的可提示基线高出 24.8 个百分点，并且以最少的点击数达到所有精度目标，同时参数更少、推理时间更短。源代码见 https://github.com/thanhhff/SelectAnyTree。

## Abstract
Automated instance segmentation of forest LiDAR point clouds is increasingly critical as forest monitoring moves toward scalable, detailed, 3D measurement. Yet, progress is constrained by label scarcity for tree instances; a single hectare can hold millions of points and hundreds of overlapping, complex crowns, making manual annotation from scratch with raw data laborious and error-prone. Annotations are often corrected from automatic pre-segmentations, but remain costly as these provide no interactive or AI-assisted refinement. Inspired by the promptable paradigm of foundation segmentation models, we propose SelectAnyTree, a promptable instance segmentation model that delineates any individual tree in a 3D forest point cloud from a few clicks. It introduces two key components: Click-to-query prompt encoder and Canopy Height Model (CHM)-guided first prompt. The former turns each click into a single content query, encoding its 3D position and positive/negative polarity together with a pooled local backbone feature. The latter provides treetops as a geometry- and ecologically guided first prompt without any user input. The resulting prompt query is then decoded into one tree mask by a state-space query decoder to efficiently capture long-range context in large-scale forest scenes with linear-time complexity. We evaluate SelectAnyTree in interactive and instance-level settings across seven diverse forest regions and an independent held-out test dataset, demonstrating strong generalization beyond the training domains. It segments a target tree to 78.2 Intersection over Union (IoU) from a single click, 24.8 points above the strongest promptable baseline, and reaches every accuracy target with the fewest clicks, while using far fewer parameters and less inference time than prior promptable models. The source code is available at https://github.com/thanhhff/SelectAnyTree.

### 2. 论文提出的方法论：核心思想、关键技术细节、算法流程

SelectAnyTree 整体分为四部分：场景编码器编码一次特征可复用；提示编码器将点击集转换为单个查询；状态空间查询解码器预测掩膜；交互式 rollout 用于训练和评估。

*   **核心思想**：将森林点云视为可提示的任务，通过用户点击（正/负）指定目标树，模型输出该树的点云掩膜。通过融入森林特有的几何先验（冠层高度模型 CHM 树梢），首次提示无需人工输入即可获得高质量的初始分割。
*   **3D 场景编码器**：对点云进行体素化，采用稀疏编码器（基于 Mamba 状态空间模型）提取体素特征 $F$，并记录点-体素映射。场景编码仅执行一次，特征可缓存复用，大幅降低多次交互时的推理开销。
*   **提示编码器**：
    *   **几何锚点**：在正点击点周围半径为 $r_p$ 的圆柱内池化骨架特征 $\bar{f}$，用于捕获局部冠层上下文。
    *   **位置与标签编码**：点击坐标通过随机傅里叶位置编码，结合可学习的正/负标签嵌入，经 MLP 映射到骨架特征维度。
    *   **符号聚合**：采用带符号的均值聚合法（正点击拉近，负点击推远）融合多点击，并与几何锚点残差相加得到最终查询 $q$。
*   **查询解码器**：采用状态空间（Mamba）查询解码器，以线性时间复杂度有效捕获大规模森林场景的长程依赖。解码器接收查询 $q$ 及其锚点位置，与缓存体素特征交互，输出体素掩膜 logits 和目标分数。
*   **CHM 引导的首次提示**：利用从场景几何自动提取的 CHM 树梢（冠层最高点）和树内点（靠近质心）作为两个正点击，构成无需用户干预的“免费”首次提示，使模型在零用户点击时即有极强的初始分割能力。
*   **交互式 Rollout 与训练**：
    *   **统一 rollout**：从 CHM+内点首发提示开始，用当前掩膜与真值对比，选择误差最大的区域（漏分或错分）自动生成一个纠正点击（正或负），循环执行 T 轮。训练与评估采用完全相同的模拟点击流程，确保一致性。
    *   **训练目标**：掩膜损失结合 BCE 与 Dice 损失，对 rollout 每一步都进行监督；同时保留辅助的树/背景分类损失和判别式嵌入损失（拉近同树体素、推远异树体素），保持骨架判别力。

*   **卓越的交互分割性能**：SelectAnyTree 仅需单次点击即可达到 78.2% IoU（域内），比最强基线 Point-SAM 高出 24.8 个百分点。达到 0.7、0.8、0.9 IoU 所需的点击次数最少。

### 8. 不足与局限：包括实验覆盖、偏差风险、应用限制等

*   **对 CHM 先验的依赖**：模型性能重度依赖从骨架树/非树预测中提取的 CHM 树梢，当骨架树预测不可靠（如极密冠层下）时，首次分割质量会降低。固定参数的异速生长窗口可能不适用于全球所有森林类型。
*   **提示类型单一**：当前仅支持点击提示，不支持框、涂鸦等其他更符合不同标注习惯的交互方式。
*   **未见域的稳健性**：尽管 LAUTx 泛化较好，但去除 CHM 的模型在 LAUTx 上表现优于带 CHM 的模型，提示了 CHM 引导需要自适应机制以应对不同森林结构，目前方法是固定的。
*   **评估局限**：虽然模拟点击协议具有一定代表性，但与真实人类标注者的纠正策略仍有差异（如人类可能一次点击多个区域，或倾向于结构化的错误），该半自动评估可能高估真实交互中的效率。
*   **下游任务验证缺失**：论文未直接验证交互分割出的树木掩膜在生物量估计、树种分类等下游生态任务中的精度影响，其实用效益有待进一步确认。
